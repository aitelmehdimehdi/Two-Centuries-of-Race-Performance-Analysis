# Race Performance Analysis (Two Centuries of Running Data)

## Overview
This project analyzes a historical dataset of running race results spanning over two centuries. The objective is to explore athlete performance trends over time using data cleaning, preprocessing, and visualization techniques.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib (pyplot)

## Workflow
- Data loading and exploration
- Data cleaning and preprocessing (handling missing values, formatting, and inconsistencies)
- Exploratory data analysis
- Visualization of athlete performance evolution over time

## Important Note
The code sections before **Project 3** were written purely for learning and experimentation purposes. The actual project implementation and analysis begin from **Project 3 onward**.

## Goal
To understand how athlete performance has evolved across historical race events and identify long-term trends in endurance running.
